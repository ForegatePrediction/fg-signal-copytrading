# 首次配置与日常使用

首次打开带指引的版本时，可逐步了解账户连接、查行情、核对成交和 Telegram 跟单。「完成指引」或「跳过指引」会记住本机选择，之后可从侧栏的「新手指引」再次打开。

## 连接 ForeGate API 账户

1. 启动客户端后进入「ForeGate API 账户」。准备 ForeGate 开通的 APP Key、APP Secret 和 API Key。
2. 已有 API 账户点「连接已有账户」，额外填写原商户用户标识 `marchantUserId` 和已有 ForeGate UID，点「验证并进入」。只有网页账户时，先确认是否已有单独的 API 账户及相应凭证。
3. 需要创建 API 账户时点「创建新 API 账户」。核对客户端生成的商户用户标识，点「注册并进入」。保存好商户用户标识和 ForeGate UID，换电脑时通过「连接已有账户」重新连接。
4. 到「账户概览」查看 UID、可用余额、冻结金额和最近成交。可在顶栏切换本机账户，到账户连接设置中验证当前账户。切换会暂停自动跟单。

## 日常功能

| 菜单 | 操作 |
|---|---|
| 账户概览 | 查看 API 账户余额和近期成交、申领记录 |
| 市场交易 | 用赛事链接、Event ID、名称搜索，或按分类浏览。选定盘口后查看订单簿，并按盘口支持的方式下单或撤单 |
| 持仓 | 查看持仓。可从支持的持仓准备限价卖出，或申领符合条件的已结算持仓 |
| 订单与成交 | 查看本机提交记录、平台订单、成交与资金流水。可按平台订单号查询状态，或核对结果不明的操作 |
| 充值提现 | 获取 Solana USDT 充值地址及查阅资金记录。充值从外部钱包发起，提现根据平台要求完成账户验证 |
| 自动跟单 | 设置市价或限价跟单、预算、监听状态，查看信号与处理结果 |
| 连接设置 | 验证 ForeGate API 账户，配置 Telegram 频道及登录 |

先检查账户概览、市场订单簿、持仓和成交记录即可做首轮只读验收。手动下单前，核对账户 UID、赛事、盘口、方向和金额。成交与撤单状态以平台订单查询结果为准。

## 提现前验证身份

1. 进入「充值提现 → 提现」，查看「账户验证方式」。如果验证器和邮箱验证码均未启用且没有恢复码，点「绑定验证器」，在身份验证器 App 中输入页面给出的密钥，再将当前 6 位验证码填回客户端。绑定完成后，妥善保存仅显示一次的恢复码。
2. 点「开启本次 MFA 验证」，选择平台为本次提现提供的方式。选「邮箱验证码」后点「发送邮箱验证码」，到当前 API 账户对应的邮箱收信。若需为已有 API 账户开通邮箱验证，可向 ForeGate 查询该 UID 的开通方式。
3. 输入验证码并点「验证」。看到「本次 MFA 验证已通过」以及金额和收款地址输入框，即可完成验证流程的验收。实际转出还需核对金额、Solana 收款地址并确认提现。

## 验证 Telegram 自动跟单

1. 在「连接设置」填写 Telegram 频道名。需要登录 Telegram 时，使用自己的 API ID、API Hash 和手机号，在客户端完成登录。 [Telegram API ID 申请说明](https://core.telegram.org/api/obtaining_api_id)
2. 在「自动跟单」点「仅监听信号」，检查「最近采集的信号」。客户端每 10 秒检查。频道暂时没有新消息时，先用市场和订单页面验收交易读取功能。
3. 在「自动跟单」选择市价或限价，保存单笔、单赛事和当日金额上限。市价按预算提交，成交价由平台撮合决定。限价可设最高买价和挂单等待时间，等待填写 0 会保留未成交委托。
4. 准备好做实盘验收时，在「连接设置」勾选「允许启用实盘跟单」并保存。回到「自动跟单」点「启用实盘跟单」，在确认窗口核对账户、频道和参数。客户端按消息发布时间筛选启用后收到的信号。
5. 查看「API 跟单记录」中的跳过原因或订单号，在「订单与成交」核对平台状态。符合条件的订单还会在提交约一分钟后比较持仓份额。暂停跟单会停止继续处理新信号，已存在委托仍可在订单页核对。

遇到提交结果不明时，先用平台订单、成交或资金流水核对，再记录处理结果，避免重复提交。
